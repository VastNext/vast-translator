# Agnes 双模型与工作台布局切换

## 问题背景

Vast Translator 目前只能比较 Google、Bing 和可选的 Azure 翻译结果，且工作台固定使用上下布局。用户需要同时比较 Agnes 2.0 与 Agnes 2.5 的翻译表现，并在长文本场景中切换为更接近沉浸式翻译文本页的左右对照布局。

## 需求

**Agnes 翻译服务**

- R1. 提供“Agnes 2.0”和“Agnes 2.5”两个可独立选择、可同时运行的翻译服务。
- R2. 默认仍只选择 Google 和 Bing；两个 Agnes 服务默认不选。
- R3. 两个 Agnes 服务支持现有语言列表中的自动检测、简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语和俄语翻译。
- R4. 两个 Agnes 服务共享服务端凭据；凭据不得发送到浏览器、日志或仓库。
- R5. Agnes 请求失败或超时时，只影响对应结果，不影响其他翻译服务。
- R5a. Agnes 使用固定、低随机性的翻译指令，将原文置于明确的数据边界中；只接受非空完整译文，空响应、截断或异常结构均作为对应 Provider 失败。
- R5b. Agnes 不自动重试或跨模型回退；上游限流、配额耗尽及服务繁忙均快速转换为对应 Provider 的独立错误。

**布局切换**

- R6. 工作台右上角提供“上下布局”和“左右布局”切换控件。
- R7. 上下布局保持当前界面结构：输入工作区在上，结果区在下，结果卡按现有响应式网格排列。
- R8. 左右布局参考沉浸式翻译文本页：原文输入工作区位于左侧，结果区位于右侧；多个结果卡在右侧纵向排列。
- R9. 窄屏设备始终使用上下布局，避免输入区和结果区过窄。
- R10. 布局选择在浏览器中保存，用户再次访问时继续使用上次选择。
- R11. 浏览器保存的是用户首选布局；窄屏仅临时强制采用上下布局，不覆盖已保存偏好，恢复宽屏后继续使用原偏好。
- R12. 布局偏好缺失、非法或无法读取时使用上下布局；窄屏下布局切换控件隐藏。

## 成功标准

- 用户可以同时选择 Google、Bing、Agnes 2.0 和 Agnes 2.5，并获得相互隔离的结果或错误状态。
- 两个 Agnes 模型完成项目现有全部语言的双向翻译验证。
- 桌面端可在上下和左右布局之间切换；左右布局中的结果按单列纵向展示。
- 移动端保持可读的上下布局。
- 默认 Provider 选择仍为 Google 和 Bing。
- 单个 Agnes 请求最多等待 30 秒；批量响应会等待所有已选 Provider 成功或进入失败状态后一次性返回。

## 范围边界

- 不提供 Agnes 模型自由输入或下拉选择；两个模型作为固定翻译服务展示。
- 不接入 Agnes 1.5，因为当前账户模型列表无该模型，真实请求也返回无可用通道。
- 不接入 Agnes Pro 系列，避免翻译场景产生不必要的延迟和潜在费用。
- 不增加流式输出、翻译历史、账户系统或新的语言选项。
- 不增加渐进式逐 Provider 返回；本次沿用现有批量响应语义。
- 不为单一部署实例新增持久化限流系统；Agnes 不重试，遇到 429 时快速失败，部署者负责按账户配额控制公开访问规模。
- 不要求布局切换改变移动端排列。

## 关键决策

- 两个 Agnes 模型并列成为独立 Provider：用户可以直接比较代际差异，且不必理解额外的模型设置。
- Agnes 默认不选：保留当前默认体验，并避免每次翻译都触发较慢的模型请求。
- 左右布局的结果纵向排列：长文本具有足够宽度，也与原文形成清晰对照。
- 上下布局保持现状：避免无关的视觉重构和行为回归。
- Agnes 使用 30 秒独立超时：实测响应存在超过现有 12 秒限制的情况，同时用明确上限避免无限阻塞整体响应。
- 凭据缺失时沿用 Azure 的现有模式：服务仍显示且可选，提交后返回该 Provider 未配置的独立错误。

## 依赖与假设

- Agnes AI 继续提供 OpenAI-compatible Chat Completions API，并允许当前 API Key 使用 `agnes-2.0-flash` 与 `agnes-2.5-flash`。
- Agnes 响应延迟存在较大波动，实施计划需要确定适当的超时策略并用逐 Provider 失败隔离保护整体结果。
- 所选原文会发送给 Agnes AI；日志不得记录原文、Authorization、完整请求体或原始上游错误体。
- Agnes 使用服务端环境变量 `AGNES_API_KEY`，并在本地与 Vercel 中作为 Secret 配置。
- 已真实验证两个模型能够翻译当前支持的全部非英语语言与英语之间的双向文本。
